**1] ****With reference to Unmanned Aerial Vehicles (UAVs), consider the following statements:** **[2025/A-42]

**I. All types of UAVs can do vertical landing.
II. All types of UAVs can do automated hovering.
III. All types of UAVs can use battery only as a source of power supply.
How many of the statements given above are correct?


a) Only one

b) Only two

c) All the three

d) None

**Answer:**
Ans: 
d) None

**Explanation:**
- Unmanned Aerial Vehicles (UAVs) are aircrafts operated without a human pilot onboard.

- **Statement I: Incorrect** – Not all UAVs can perform vertical landing; only certain types this capability. Most of the UAVs require runways and land like an aeroplane.

- **Statement II: Incorrect** – Automated hovering is possible mainly for certain UAVs, not for all types.

- **Statement III: Incorrect** – UAVs can be powered by various sources such as batteries, gasoline, hybrid engines, or solar energy, not just batteries.

- Hence, none of the statements are correct. Correct Ans: 
d) ) None
