### Question
**3] With reference to Visible Light Communication (VLC) technology, which of the following statements are correct? [2020]**

1. VLC uses electromagnetic spectrum wavelengths 375 to 780 nm.
2. VLC is known as long-range optical wireless communication.
3. VLC can transmit large amounts of data faster than Bluetooth.
4. VLC has no electromagnetic interference.

Select the correct answer using the code given below:
a) 1, 2 &amp; 3 only
b) 1, 2 &amp; 4 only
c) 1, 3 &amp; 4 only
d) 2, 3 &amp; 4 only

**Answer:**
Ans: c) 1, 3 &amp; 4 only

**Explanation:**
- Visible Light Communication (VLC) technology is a method of data transmission using visible light.



- The technology uses visible light from LEDs (Light Emitting Diodes) to transmit data. Data is encoded into the light signals emitted by LEDs, which are then detected and decoded by photodetectors or specialized sensors.



- As the name suggests, **it uses visible light for communication, hence the spectrum wavelengths are in the range of 375 to 780nm.**



- VLC can achieve data transfer speeds ranging from hundreds of megabits per second (Mbps) to **several gigabits per second (Gbps).** Laboratory setups have demonstrated speeds exceeding 10 Gbps.



- **Bluetooth on the other hand, offers data transfer speeds up to 2 Mbps**, with Bluetooth 5.2 providing slightly better performance but still far below the speeds achievable with VLC.



- Unlike radio frequency (RF) communication, **VLC is not susceptible to electromagnetic interference,** making it useful in environments where RF signals are restricted or unreliable.



- Since light cannot penetrate walls, VLC offers secure data transmission within a confined space, useful for secure communications in offices or homes.



- One of the main challenges of VLC is line-of-sight requirement. The tech requires a direct line of sight between the transmitter and receiver. **Thus, it cannot be used over long range.**



- **Thus, options 1,3 and 4 are correct.**
