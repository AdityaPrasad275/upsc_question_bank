# UPSC Economy Questions Viewer

A simple web application to view processed UPSC economy questions with detailed research and explanations.

## Features

- Sidebar with list of all questions
- Detailed view of each question including:
  - Question text and options
  - Correct answer
  - Explanation
  - Research summary, key facts, and sources
  - Search metadata

## Hosting

This is a static website that can be hosted on:
- GitHub Pages
- Netlify
- Vercel
- Any static web host

## Local Development

Open `index.html` in a web browser. Make sure the `data/` folder contains the JSON files.

## Data

The question data is stored in `data/question_*.json` files, generated from Anthropic's batch processing.
