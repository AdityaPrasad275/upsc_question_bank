### Question
**1] The terms “WannaCry , Petya and Eternal Blue” sometimes mentioned in the news recently are related to: [2018]**

a) Exoplanets
b) Cryptocurrency
c) Cyber attacks
d) Mini Satellites

**Answer:**
Ans: c) Cyber attacks

**Explanation:**
- The terms given i.e. “WannaCry,” “Petya,” and “EternalBlue” are related to **cybersecurity threats**, specifically referring to prominent malware attacks and vulnerabilities.



- **WannaCry** is a ransomware attack that occurred in May 2017. It targeted computers running the Microsoft Windows operating system by encrypting data and demanding ransom payments in the form of Bitcoin for decryption.



- It exploited a vulnerability in the Windows operating system called **EternalBlue**, which was originally developed by the NSA (National Security Agency) and later leaked by a group called the Shadow Brokers.



- **Petya**, also known as NotPetya, is another ransomware attack that occurred in June 2017, shortly after the WannaCry attack. Like WannaCry, Petya targeted Windows-based systems, encrypting files and demanding ransom payments. However, it differed from traditional ransomware in that it aimed to cause widespread disruption rather than generate revenue.



- As mentioned above, **EternalBlue** is a software vulnerability in the Windows operating system’s Server Message Block (SMB) protocol. It was originally discovered by the NSA and used as a cyber weapon for espionage purposes. The EternalBlue vulnerability allows for remote code execution, enabling attackers to spread malware across networks and compromise vulnerable systems.



- Recent cybersecurity threats and malware names include Ryuk, SolarWinds, Colonial Pipeline, Log4j, PrintNightmare etc.
