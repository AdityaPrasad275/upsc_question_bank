### Question
**3] The identity platform ‘Aadhar’ provides open “Application Programming Interfaces (APIs)”. What does it imply? [2018]**

1. It is integrated into an electronic device.
2. Online authentication using iris is possible.

Which of the statements given above is/are correct?
a) 1 only
b) 2 only
c) Both 1 and 2
d) Neither 1 nor 2

**Answer:**
Ans: c) Both 1 and 2

**Explanation:**
- In simple words, an API, or Application Programming Interface, is like a set of rules that lets different software programs talk to each other. It’s like a language that helps them understand each other’s requests and responses. So, when one program wants to use the features of another program, it can do so through the API without knowing all the details of how that program works. It’s like a bridge that connects different parts of a digital world, making it easier for them to work together.



- For example, a **weather API** provides access to weather data, such as temperature, humidity, and forecasts. Apps and websites can use this API to display current weather conditions or provide weather alerts to users.



- Multiple things are possible with the use of API. With the APIs provided by Aadhar, things like OTP generation and validation, Iris scan validation, fingerprint validation, e-signature, e-KYC are possible. And yes, it can be integrated into an electronic device (since the definition of electronic device itself is too broad).



- Also know that Aadhar can change these APIs over time. **However, pretty much anything that will happen with Aadhar (on any online system) will be happening through use of APIs.**



- **Thus, both the given statements are correct.**
