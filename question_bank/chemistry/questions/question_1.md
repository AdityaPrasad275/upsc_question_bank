**1] ****Consider the following substances:** **[2025/A-45]

**I. Ethanol
II. Nitroglycerine
III. Urea
Coal gasification technology can be used in the production of how many of them?


a) Only one

b) Only two

c) All the three

d) None

**Answer:**
Ans: 
c) All the three

**Explanation:**
- **Statement I: Correct** – Coal gasification produces syngas (CO + H₂) which can be converted catalytically or via fermentation into ethanol (coal-to-ethanol processes exist).

- **Statement II: Correct** – Though not made directly, syngas helps produce chemicals (like hydrogen and methanol) needed to make nitroglycerine.

- **Statement III: Correct** – Coal gasification provides hydrogen, which can be used for ammonia manufacturing which in turn is used to make urea, so urea production can be linked to coal gasification.
