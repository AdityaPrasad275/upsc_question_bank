### Question 4
**1] With reference to street-lighting, how do sodium lamps differ from LED lamps? [2021]
**
1) Sodium lamps produce light in 360 degrees but it is not so in the case of LED lamps.
2) As street-lights, sodium lamps have longer life span than LED lamps.
3) The spectrum of visible light from sodium lamps is almost monochromatic while LED lamps offer significant colour advantages in street-lighting.
4) Select the correct answer using the code given below.


a) 3 only

b) 2 only

c) 1 and 3 only

d) 1, 2 and 3

**Answer:**
Ans: 
c) 1 and 3 only

**Explanation:**
Option 1 states that Sodium lamps produce light in 360 degrees but it`s not the case with LED lamps. This is accurate since Sodium lamps emit light in a full 360 degrees, whereas LED lamps emit light in a specific direction, reducing the need for reflectors and diffusers that can trap light.

Option 2 suggests that Sodium lamps as street-lights have a longer lifespan than LED lamps. However, this is incorrect, because LED bulbs have a life span of up to 50,000 hours, significantly longer than that of Sodium lamps which typically only last between 12,000-24,000 hours.

Option 3 claims that the spectrum of visible light from Sodium lamps is almost monochromatic while LED lamps offer significant colour advantages in street-lighting. This is true as Sodium lamps produce a narrow spectrum of light in the yellow range, making things appear monochromatic yellow or grey, whereas LED lamps produce white light which allows for better color recognition.

So, the correct answer is Option 3, which includes 1 and 3 only. The viability of option 2 is the only difference between Options 3 and 4.
