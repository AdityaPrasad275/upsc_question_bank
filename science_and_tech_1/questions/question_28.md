### Question
**6] “3D Printing” has applications in which of the following? [2018]**

1. Preparation of confectionery items
2. Manufacture of bionic cars
3. Automotive industry
4. Reconstructive surgeries
5. Data processing technologies

select the correct answer using the code given below;
a) 1, 3 and 4 only
b) 2,3 and 4 only
c) 1 and 4 only
d) 1, 2, 3, 4 and 5

**Answer:**
Ans: d) 1, 2, 3, 4 and 5

**Explanation:**
- 3D printing, also known as additive manufacturing, is a process of creating three-dimensional objects from a digital file by layering materials such as plastic, metal, or resin.



- 3D printing is used in various fields, including healthcare for custom prosthetics, automotive for prototyping parts, aerospace for lightweight components, construction for building models, fashion for unique designs, and education for creating hands-on learning tools.



- Regarding the options given, 3D printing can be potentially be used in all the places given in the question. 



- **Hence the answer is d) 1, 2, 3, 4 and 5**
